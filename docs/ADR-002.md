# LLM Router Pro — Architecture Decision Records

## ADR-001: FastAPI over Flask
FastAPI provides native async support, automatic OpenAPI docs, and Pydantic validation — critical for LLM gateway performance.

## ADR-002: PostgreSQL for Metrics Storage
PostgreSQL with JSONB allows flexible schema evolution for request logs while maintaining ACID compliance for billing data.

## ADR-003: HMAC-SHA256 for API Authentication
HMAC provides cryptographic integrity verification without exposing secrets in transit. compare_digest() prevents timing attacks.

## ADR-004: Prometheus for Metrics
Prometheus is the industry standard for Kubernetes monitoring. Custom metrics (cost, latency per provider) integrate seamlessly.

## ADR-005: Circuit Breaker Pattern
pybreaker prevents cascading failures when LLM providers are down. Fallback to local model ensures service continuity.

## ADR-006: Multi-Stage Docker Build
Python 3.12-slim reduces image size by ~60% compared to full image. Multi-stage separates build and runtime dependencies.
